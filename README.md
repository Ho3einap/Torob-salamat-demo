# 🏥 سامانه هوشمند مکان‌یابی داروخانه و جستجوی داروهای نایاب (Torob Salamat)

این پروژه یک پلتفرم فول‌استک در حوزه **سلامت و لجستیک دارویی (HealthTech)** است که چالش اتلاف وقت بیماران در یافتن داروهای کمیاب و دسترسی به نزدیک‌ترین داروخانه‌های فعال را حل می‌کند. سیستم با تحلیل هوشمند نسخه و جستجوی چندعاملی، بهترین داروخانه‌ها را بر اساس موجودی زنده، امتیاز کیفی شرکت‌های سازنده و فاصله فیزیکی رتبه‌بندی می‌کند.

---

## 🚀 ویژگی‌های کلیدی (Key Features)

- **🔍 رتبه‌بندی چندعاملی داروخانه‌ها (Geo-Proximity & Multi-Criteria Ranking):** محاسبه مسافت جغرافیایی و تخمین زمان سفر (فرمول Haversine) ترکیب‌شده با موجودی انبار، شبانه‌روزی بودن و رتبه رضایت مشتریان.
- **💊 ارزیابی کیفی سازندگان دارو (Manufacturer Quality Matrix):** رتبه‌بندی و مقایسه داروهای مشابه بر اساس شاخص‌های کیفی، استانداردهای cGMP و برند سازنده.
- **📋 تحلیل و انطباق نسخه پزشک (AI-Assisted Prescription Parsing):** استخراج هوشمند اقلام دارویی، دوز و تعداد از نسخه‌های ثبت‌شده و تطبیق لحظه‌ای با کل سبد دارویی موجود در انبار داروخانه‌ها.
- **⚡ رزرو آنی بدون تداخل همزمانی (Concurrency-Safe Reservation):** جلوگیری قطعی از تداخل‌های Race Condition و کسری موجودی با به‌روزرسانی‌های اتمیک در پایگاه داده[cite: 2].
- **🔔 سیستم هشدار و اعلان داروی کمیاب (Rare Drug Alert System):** ثبت درخواست و اطلاع‌رسانی پیامکی خودکار به بیمار به محض شارژ مجدد دارو در داروخانه‌های اطراف[cite: 2].

## 🛠 پشته فناوری (Tech Stack)

### بک‌اند (Backend)

- **فریم‌ورک:** [NestJS](https://nestjs.com/) (ماژولار و مبتنی بر TypeScript)[cite: 2]
- **پایگاه داده:** [MongoDB](https://www.mongodb.com/) به همراه [Mongoose ODM](https://mongoosejs.com/)[cite: 2]
- **سیستم داده درون‌حافظه‌ای:** `mongodb-memory-server` برای راه‌اندازی سریع محیط‌های تست، توسعه و دمو بدون وابستگی به زیرساخت خارجی[cite: 2]

### فرانت‌اند (Frontend)

- **فریم‌ورک:** [Vue 3](https://vuejs.org/) (Composition API + TypeScript)[cite: 2]
- **ابزار ساخت:** [Vite](https://vitejs.dev/)[cite: 2]
- **مدیریت حالت (State Management):** استور واکنشی تمیز بر پایه الگوهای ماژولار[cite: 2]
- **استایل‌دهی:** [Tailwind CSS](https://tailwindcss.com/) با پشتیبانی کامل از چینش راست‌به‌چپ (RTL) و آیکون‌های Lucide[cite: 2]

## 📁 ساختار معماری پروژه (Project Architecture)

```text
├── client/                     # فرانت‌اند مجزا (Vue 3 SPA)
│   ├── src/
│   │   ├── components/         # کامپوننت‌های ماژولار و مودال‌ها
│   │   ├── stores/             # مدیریت وضعیت اپلیکیشن و داده‌های کاربر
│   │   ├── views/              # صفحات اصلی (چت هوشمند، انبار، نسخه‌ها، سفارشات)
│   │   └── services/           # کلاینت ارتباط با API
│   └── vite.config.ts          # تنظیمات Vite و پروکسی روت‌های API
│
├── server/                     # بک‌اند مجزا (NestJS Architecture)
│   ├── src/
│   │   ├── ai/                 # موتور محاسبات مسافت و استخراج نیازمندی دارویی
│   │   ├── catalog/            # کاتالوگ داروها و سازندگان
│   │   ├── pharmacies/         # مدیریت و جستجوی موقعیت داروخانه‌ها
│   │   ├── reservations/       # چرخه عمر رزرو دارو و اعتبارسنجی همزمانی
│   │   ├── prescriptions/      # پردازش و آنالیز نسخ
│   │   ├── database/           # اسکیماهای Mongoose و ماژول اتصال
│   │   └── seed/               # سرویس تزریق داده‌های نمونه اولیه
│   └── main.ts                 # نقطه ورودی سرور NestJS
└── package.json
```
